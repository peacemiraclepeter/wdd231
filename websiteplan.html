Miracle Tech Hub

Website Project Site Plan

Site Name

Miracle Tech Hub

Reason for Selection: This name represents a technology community and innovation center based in Port Harcourt, Rivers State, Nigeria. "Miracle" connects to the location while "Tech Hub" clearly communicates the focus on technology, innovation, and community building.

Optional Domain: miracltechhub.org

Site Purpose

The Miracle Tech Hub website serves as a central platform for technology professionals in Port Harcourt:

  • Community Directory: Directory of local tech companies and professionals
  • Event Information: Tech meetups, workshops, and hackathons
  • Learning Resources: Training programs and mentorship
  • Membership Portal: Join the hub and view benefits
  • News & Updates: Local tech ecosystem news
  • Resource Sharing: Co-working spaces and tools

Scenarios

"I'm a software developer new to Port Harcourt. How can I connect with other tech professionals and find out about upcoming tech events?"

Answer: Events calendar, membership directory, and "Join Us" section

"I run a tech startup and need affordable office space. What membership options does Rivers Tech Hub offer?"

Answer: Membership page with tiers (NP, Bronze, Silver, Gold) and online application

Color Scheme

Carefully selected colors for professionalism and innovation:

Color Usage:

  • Deep Navy (#1e3a5f): Headings, header/footer backgrounds, primary buttons
  • Teal (#2e8b8b): Subheadings, links, accents, hover states
  • Warm Orange (#f4a261): CTAs, highlights, icons, borders
  • Light Gray (#f8f9fa): Page background, cards
Note: This document uses the exact color scheme defined above.

Typography

Two complementary Google Fonts selected:

Montserrat (Sans-Serif)

Usage: All headings, navigation, buttons
Weights: 400, 600, 700

Open Sans (Sans-Serif)

Usage: Body text, paragraphs, lists, forms
Weights: 400, 600
